# 个人数据导出

用户在私聊中发送 `/export_my_data`，会收到 `telegram-my-data.json`（UTF-8 JSON，`schemaVersion: 3`）：

- `user`：Telegram ID、用户名、名字、语言、创建、更新和最后活动时间（不含内部 ID）。
- `tickets`：该用户的全部工单（最多 1000 个），包含编号、状态、创建、解决和最后活动时间。
- `messages`：本页消息，双向，从新到旧，每页最多 100 条。每条包含工单号、方向、文字、附件类型和时间；客服发出的消息还带「送达你的时间」。
- `pagination`：`hasMore` 与 `nextCursor`。机器人会给出下一页的完整命令 `/export_my_data <cursor>`。

`/export_my_replies` 是旧命令名，效果相同。

## 权限

- 身份只取自 Telegram 的 `from.id`，参数里不能指定其他用户。
- 每页查询都限定在该用户自己的工单内。游标只表示翻页位置，不授予任何权限；长度、格式、版本、时间戳和 ID 都会校验，无效时提示从第一页重新开始。
- 文件只发回本人私聊，不写日志，也不另存文件。

## 边界

- 分页不是同一时间点的快照：导出期间如果有新消息或删除，前后页可能不一致。
- 只包含本服务数据库中的数据，不包含 Telegram 平台自身的聊天记录。
- 导出和删除不受限流影响。需要删除时，先导出，再使用 `/delete_my_data`。
